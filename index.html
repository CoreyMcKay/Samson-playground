v0.9.1

OrcaAtlas: what broke and how I'd fix it — 2026-09-17

The orca tracker still renders, but the sightings feed flatlined. Diagnosis: the upstream providers (iNaturalist, GBIF) are healthy — tens of thousands of records — so the failure is the brittle public CORS proxies in between. The fix is a server-side route handler that fetches directly and kills the proxy dependency. Classic lesson: never build your data pipeline on someone else's free proxy.

v0.9.0

Detection as code — 2026-09-16

A detection nobody can version, test, or roll back is a rumor, not a control. Treating Snort/Suricata rules and SOAR playbooks like software — reviewed, tested, deployed — is the difference between a SOC that hunts and a SOC that hopes. More on this soon.
